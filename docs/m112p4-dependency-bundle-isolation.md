# M11.2P4 — Dependency-Closed Component Bundle Isolation

M11.2P4 adds one bounded extension to the validated D3 diagnostic: a minimal,
dependency-closed bundle of exactly two supported AST components. It is not
arbitrary interaction search. A bundle is considered only when a deterministic
AST binding proves an edge, and closures larger than two abstain.

The implementation builds repair and transfer hybrids from deep AST copies,
checks PostgreSQL parse round trips, enforces non-target invariance, reuses D2
typed comparison and hashing, and preserves P0 entitlement. A successful
result means only that the bundle bidirectionally carries the observed witness
behavior under the frozen diagnostic fixture contract. It is not a universal
root-cause or SQL-equivalence claim.

The independent controls cover four alias-dependent projection/order bundles,
co-occurrence and singleton negatives, a three-node closure, unsafe syntax,
and P0 blocking. Historical application is mechanically limited to the 16
P0-eligible D3 no-isolation pairs: 15 P0-blocked pairs and the single
dimensional witness are closed/excluded.

Implementation and measurement are the default after a bounded mechanism has
passed selection. Unresolved cases abstain. A failed implementation gets fixed
or removed. A validated diagnostic result leads to the next bounded
implementation. Do not repeatedly reopen mechanism selection.

The LLM proposes. Deterministic software decides what may execute.

Don’t improve what looks suspicious. Improve the decision boundary the evidence
proves is failing.

Once a repeated bounded bundle is independently isolated, implement the
generation-side intervention instead of reopening mechanism selection.

Dependency closure is not arbitrary interaction search. Only the minimum
structurally required size-2 bundle may extend a failed single-component
substitution. Bundles larger than two are outside this residual line. If no
repeated size-2 dependency-closed bundle is isolated, close the current
historical component-isolation line rather than continuing to mine the same
cases.

The independent validation passed: 4/4 known dependency bundles isolated,
zero false bundle isolations, 100% non-target invariance and reproducibility,
and D2/D3 regressions passed. Historical application completed on 16 P0-clean
pairs (32 arms); all 32 arms reached `DEPENDENCY_CLOSURE_TOO_LARGE` because
the qualified historical expressions require the relational binding in
addition to projection/order, and P4 does not test size-three bundles. No
size-two bundle had positive historical support, so the classification is
`M112P4_NO_REPEATED_DEPENDENCY_BUNDLE_ISOLATED` and the D2/D3 dependency-bundle
line is closed for this consumed residual.
