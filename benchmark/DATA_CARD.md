# Decision-SQL Bench v0.1 data card

All data is deterministic synthetic data generated by `benchmark.authoring` with seed `3401` and generator version `m34-authoring-v1`. The three domains are commerce operations, fleet operations, and customer support operations. Each pack has ten meaningful tables, mixed relational/scalar/JSONB fields, documented relationships, and deliberate physical authority traps. Base data is large enough for grouped and temporal behavior while remaining practical for repeated validation.

The pilot is 30 cases across four governed behaviors. It includes NULLs, zero values, multiple groups, ties, temporal boundaries, nested JSON paths, and rows with no matching child entity. Counterfactuals are transactional patches, never semantic-authority mutations.

Limitations: this is a machine-authored development pilot, not a human-reviewed or untouched final evaluation set. The two reference implementations were authored in one process, so `human_independent_review` remains false. Domain coverage is intentionally narrow at three databases and PostgreSQL only. No external benchmark questions, schemas, data, business rules, or protected gold SQL were reused.
